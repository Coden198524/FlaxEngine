## 详细测试步骤

### 1. 编译验证

```bash
# 清理构建
./clean.bat

# 重新编译
./build.bat

# 检查编译输出
# 预期：0 errors, 0 warnings (或仅有预期的警告)
```

### 2. 运行单元测试

```bash
# 运行所有测试
./FlaxEngine.exe -test

# 预期输出：
# === Running RenderGraph Unit Tests ===
# Passed: 7, Failed: 0
# === Running RenderGraph Integration Tests ===
# Passed: 12, Failed: 0
```

### 3. 基础渲染测试

1. 启动编辑器
2. 打开测试场景：`Content/TestScenes/BasicScene.scene`
3. 进入播放模式
4. 验证：
   - 所有物体可见
   - 材质正确显示
   - 无渲染错误或警告

### 4. 光照测试

1. 打开场景：`Content/TestScenes/LightingTest.scene`
2. 验证每种光源类型：
   - 方向光：检查光照方向和强度
   - 点光源：检查衰减和范围
   - 聚光灯：检查锥形和边缘
3. 验证阴影：
   - 阴影边缘清晰
   - 无闪烁或伪影
   - 级联过渡平滑

### 5. 后处理测试

1. 打开场景：`Content/TestScenes/PostProcessTest.scene`
2. 逐个启用后处理效果
3. 对于每个效果：
   - 验证效果可见
   - 调整参数，确认响应
   - 检查性能影响

### 6. 性能测试

1. 打开场景：`Content/TestScenes/PerformanceTest.scene`
2. 启用性能分析器（F11）
3. 记录关键指标：
   - 帧时间
   - Draw calls
   - 内存使用
   - GPU 时间
4. 对比基准值

### 7. 稳定性测试

1. 启动编辑器
2. 加载复杂场景
3. 让场景运行至少30分钟
4. 监控：
   - 内存使用（应该稳定）
   - 帧率（应该稳定）
   - 无崩溃或错误

## 测试场景要求

确保以下测试场景存在并正确配置：

### BasicScene.scene
- 简单几何体（立方体、球体、平面）
- 基础材质
- 一个方向光
- 简单的后处理

### LightingTest.scene
- 各种光源类型
- 不同材质的物体
- 阴影测试对象
- 级联阴影可视化

### PostProcessTest.scene
- 各种后处理效果的展示
- 可调节的后处理参数
- 对比区域（有/无后处理）

### PerformanceTest.scene
- 高复杂度场景
- 大量 draw calls
- 多个光源
- 完整的后处理链

### MaterialShowcase.scene
- 各种 PBR 材质
- 不同的金属度和粗糙度
- 透明和半透明材质
- 特殊材质（发光、次表面散射等）

## 附录：常见问题

### Q: 测试失败怎么办？
A: 记录详细的问题信息，包括重现步骤、环境信息和日志，然后提交问题报告。

### Q: 性能测试不达标怎么办？
A: 使用性能分析工具定位瓶颈，优化关键路径，或调整资源分配策略。

### Q: 视觉差异如何判断是否可接受？
A: 如果差异 < 1% 且无明显视觉瑕疵，通常可以接受。对于关键视觉效果，需要人工审核。

### Q: 如何处理平台特定的问题？
A: 记录平台信息，检查是否是已知限制，如果是新问题，提交平台特定的问题报告。
